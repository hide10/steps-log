# steps-app

歩数を自分の手元に持ち続けるための、個人用の歩数計。

Android アプリで歩数を記録し、`steps.json` として書き出して、
ブラウザで週/月/年の平均を見る。課金アプリやクラウドに預けっぱなしにしない。

```
Android アプリ → クラウド(Google ドライブなど) → ブラウザで表示
```

## できること

- 歩数の記録（端末のセンサーと Health Connect の両方に対応）
- 目標設定と達成リング、連続達成日数（現在・自己ベスト）
- **目標の履歴**。目標を変えても、過去の達成や連続日数は当時の目標のまま
- 日 / 週 / 月 / 年 の集計と、前の期間との比較
- **歩いた時間帯**。1日のどこで歩いたかを24時間の帯で見る
- 距離・消費カロリーの推定
- ホーム画面ウィジェット4種
- 体重・睡眠の取り込みと推移。心拍・血圧など9種の健康データ（Health Connect）
- 目標の達成と「あと少し」の通知、計測が止まったときの自己診断
- 共有用の画像づくり（何を載せるかは自分で選ぶ。既定は歩数と日付だけ）
- エクスポート / インポート（JSON=完全バックアップ、CSV=分析用）
- テーマとアクセントカラー

**他人と比べる機能は作らない。** チャレンジやランキングは一人用という前提と
衝突するため対象外。競争が欲しければ「過去の自分と比べる」形にしている。

## 構成

| ディレクトリ | 中身 |
| --- | --- |
| `android/` | Kotlin + Compose + Room + WorkManager + Health Connect |
| `web/` | **サーバレスの Web ビューア。** HTML と JS だけで動く |
| `server/` | 常駐させたい人向けの Bun + Hono ダッシュボード（任意） |
| `deploy/` | server を常駐させる場合の設定例 |

**`web/` はデータがブラウザから出ない。** 読み込んだ歩数はどこにも送信されず、
集計もグラフ描画もすべてブラウザ内で完結する。

## 使いはじめる

### 1. アプリを入れる

[Releases](../../releases) から APK を落として端末に入れる。
Play ストア外なので、初回は「提供元不明のアプリ」の許可を求められる。

自分でビルドする場合:

```bash
cd android
ANDROID_HOME=<Android SDK> ./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk を端末に入れる
```

端末側で次を設定する。

- 「身体活動」の権限を許可（歩数センサーの読み取りに必須）
- Health Connect の権限を許可（アプリが止まっていた間の歩数も拾える）
- **バッテリー使用量を「制限なし」に**（OEM の省電力でアプリが眠らされるため）

### 2. 書き出し先を選ぶ

アプリの 設定 → バックアップ先 → 「保存先を選ぶ」。
**フォルダ選択で Google ドライブを選べば、そのままドライブに保存される。**
OAuth も API キーも要らない。端末内のフォルダでもよい。

以降 1日1回 `steps.json` が自動で書き出される。

### 3. 見る

`web/index.html` をブラウザで開き、`steps.json` を選ぶ。
一度読めば次回からは開くだけでよい。

## 開発

```bash
./dev.sh          # ビルド → テスト → 実機インストール
```

環境ごとの違いは `dev.env` に書く（`dev.env.example` を参照）。

```bash
cd android && ./gradlew test    # Android の単体テスト
cd server  && bun test
cd web     && bun install && bun test test/
```

設計方針とハマりどころは [`AGENTS.md`](AGENTS.md)、
作業の引き継ぎは [`HANDOFF.md`](HANDOFF.md) にある。

## リリース用のビルド

`assembleRelease` は署名の設定を探す。**鍵もパスワードもリポジトリには入っていない。**

```
keystore.properties        # リポジトリ直下、または ~/steps-app-keys/ に置く
  storeFile=<.jks のパス>
  storePassword=...
  keyAlias=...
  keyPassword=...
```

見つからなければ署名なしのままビルドされるので、clone しただけでも組める。

**鍵は失うと二度と作り直せない。** 別の鍵で署名した APK は、同じアプリの更新として
インストールできない（端末で一度アンインストールが必要になり、記録が消える）。
鍵ファイルとパスワードは、リポジトリとは別の場所に控えておくこと。

## 集計の規則（3実装で揃えること）

集計は Kotlin / SQL / JS の3か所にある。**規則がズレると同じ週で違う数字が出る。**

- **週は月曜始まり。** `strftime('%Y-%W')` 相当でグルーピングしない
  （年をまたぐ週が分断される）。「その週の月曜日」の日付でまとめる
- **平均の分母は記録がある日だけ。** 0歩の記録は含め、未計測の日は含めない

Kotlin と SQL と JS が同じ結果になることを、1200日ぶんの期待値で
突き合わせるテストがある（`WeekStartCrossCheckTest` / `web/test/aggregate.test.js`）。
