# 歩数ログ ビューア（サーバレス）

`steps.json` を読み込んで、週/月/年の平均や連続達成日数を見る**静的な Web ページ**。

```
スマホアプリ → Google ドライブ → PC のブラウザでこのページを開く
```

## 特徴

- **常駐サーバが要らない。** HTML と JS だけで動く
- **データがブラウザから出ない。** 読み込んだ歩数はどこにも送信されず、
  集計もグラフ描画もすべてブラウザの中で完結する。
  一度読めば `localStorage` に残るので次回は開くだけ
- 依存ライブラリなし（テストのみ linkedom を使う）

## 使い方

`index.html` をブラウザで開いて、データを読ませる。**外部ライブラリも
ダウンロードも要らない**（集計ロジックは HTML に埋め込んである）。

### フォルダを選ぶ（おすすめ）

「フォルダを選ぶ」で `steps.json` が入ったフォルダを指定する。
**一度選べば次回からは開くだけで最新が読まれる。**

Google ドライブのデスクトップ版を入れていれば、ドライブは
`G:\マイドライブ\...` のようにフォルダとして見えるので、
端末が上書きした `steps.json` をそのまま読める。
**ダウンロードも rclone も要らない。** ローカルのフォルダでも同じ。

> フォルダ選択は File System Access API を使うため、
> `http://` か `https://` で開いたときだけ有効
> （`file://` では下の「ファイルを開く」を使う）。

### ファイルを開く

`steps.json` を直接選ぶ。`file://` でも動く。

### そのほか

`#week` `#month` `#year` を URL の末尾に付けると、その期間で開く。

## 集計の規則

**`android/.../domain/Aggregate.kt` および `server/src/aggregate.ts` と同じでなければならない。**
ズレると同じ週なのに違う数字が出る。

- 週は月曜始まり。`%Y-%W` 相当でグルーピングしない（年をまたぐ週が分断される）
- 平均の分母は記録がある日だけ。0歩の記録は含め、未計測の日は含めない

`test/aggregate.test.js` が、SQL で生成した 1200 日ぶんの期待値
（`test/sql-week-starts.csv`）と突き合わせて一致を保証している。

## テスト

```bash
cd web && bun install && bun test test/
```

- `aggregate.test.js` — 集計・ストリーク・週境界（SQL との一致）
- `render.test.js` — linkedom で実際に DOM を組み立て、画面に出る中身を検証
